# Listen-Fire Builder

Teaches Claude to build automations on your real tools with Listen-Fire: when
something happens — an email arrives, a CRM record changes, a schedule fires —
data moves where it should, the same way every time.

Pair it with your deployment's Automation MCP connector: the connector gives
Claude the tools, this skill teaches Claude how to build with them.

## Install

```bash
claude plugin marketplace add ./plugins
claude plugin install listen-fire-builder@listen-fire-plugins
```
