A record's change carries the changed field's value and says how it changed, as Airtable's changes carry theirs. `Field Change` is `set`, `changed` or `cleared` (a field value's `created`, `updated` and `deleted` events). `Current` is the record holding only the changed field, at the value set or changed to, and `Previous` at the value cleared, each typed by the record's own field (a dropdown by its label; a field holding several values, as the list of the one value added or removed). Affinity sends no value a change replaced, so `Previous` is unknown on a `changed` change. A field the record type does not name marks `Field`, `Current` and `Previous` unknown, so a filter on them is undecided (an `Arrival Not Judged`) where `c.Field == null` passed it. An opportunity list's scalar columns are its entries' fields, read from the workspace's whole field catalog, read-only; its change names them, its `Field` still text as 0.13.0 typed it. The upgrade note on `organization.updated` offers ``AND c.`Field Change` == null``.
