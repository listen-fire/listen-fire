The routing rule for an inbound event is public in `public/inbound`, beside `eventMatchesTriggerScope`: `listenHearsCredential(listened, delivered)` (a listen whose construction names a credential hears only that credential's deliveries; a listen that names none, or a delivery addressed to the module's install, hears or reaches every one), and `listenerHearsDelivery(listener, { adapterType, credentialName?, event })`, the whole rule for one listen. It is the rule `lf` and the hosted product route by; a shared table of cases (`packages/engine-contracts/conformance/listen-hears.json`) holds the TypeScript and `lf`'s Rust to it.
