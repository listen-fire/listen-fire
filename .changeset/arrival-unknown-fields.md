An arrival's landing and each parent may name the fields its module could not read (`unknown`, adapter protocol 2.6). The listen judge leaves a listen whose filter reads one undecided, never reading the field as absent, and judges every other listen as usual. Slack names a message's `Mentions App` unknown when it cannot read the app's bot user (`auth.test`), and a carried channel's `Name` when it cannot read the channel (`conversations.info`), instead of guessing or dropping the channel.
