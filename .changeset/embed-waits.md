A run that awaits a module's listenable edge parks until something lands there: `arrive(tenant, { adapterType, arrivals })` hands the host what one of the tenant's modules says arrived (adapter protocol 2.5), and each run waiting on it steps on. `tick` steps runs an arrival woke as well as runs whose timer is due. An arrival no run waits on yet is kept for an hour, for a run that starts waiting on its record.
