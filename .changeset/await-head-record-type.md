`awaitKeys` is told each head's record type: `AwaitHead` (and `WireAwaitHead`) gains `recordType?`, the record's type as its module names it, wherever the host knows it (adapter protocol 2.6). The embedder names it for a run's trigger from the arrival's landing. A module whose record types number their ids apart qualifies its keys by it, in its answer and in each arrival's `key` alike. A listen judge's skip may carry a `reason` (`{ skips, reason? }`) when the record it carried for that hop is of another record type.
