`MOV_UNKNOWN_POSITION` on a parameter type names the address to write where the catalog says which one it is: a longer walk names the record it lands on (`<chat-[:File]->>`), and a hop naming a position a connection with only one no longer has names that one. `listen-fire upgrade` lists it and applies it only with `--all`.
