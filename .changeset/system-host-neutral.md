`@lf/system`'s text for authors names no particular host. Its manifest, its handbook section and its event kinds' and fields' descriptions say what each kind means and that which kinds arrive depends on the host running the program (a host reports a kind only if it supplies the facts for it), so any host can use the published module as it is. The facts about listen-fire's own reports stay in docs/contracts/system-events.md. The root's display name is `System`, where it was `Listen-Fire`.
